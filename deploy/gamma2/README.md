# Gamma 2 Setup Files

Follow [the setup guide](../../docs/gamma2.md) if you are rebuilding the
server or giving lab members access. This folder holds the files used by
that guide.

- `host/` contains the Samba share, USB passthrough and udev settings,
  clock configuration, archive timer, and `setup-shared.sh` for lab access.
- `windows/` contains `setup-vm.ps1` and the VM's `.env` template.

For everyday measurements, start with [the project README](../../README.md).
